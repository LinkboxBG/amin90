## 1. Бранд философия

**АМИН** е денонощна траурна/погребална агенция в гр. Стамболийски, обслужваща региона (Цалапица, Кричим, Огняново) и цялата страна. Слоган: **„Чест, достойнство и почтеност."**

| Принцип | Какво означава за дизайна |
|---|---|
| **Достойнство** | Сдържаност, много негативно пространство, никакви крещящи елементи или тежки анимации. |
| **Доверие** | Видими контакти 24/7, ясен процес, прозрачност. Семейството трябва да усети сигурност за секунди. |
| **Спокойствие** | Бавни преходи, мек ритъм, приглушена фотография. |
| **Трайност** | Класическа serif типография (Playfair Display italic), премерени детайли — дизайн, който не остарява. |

**Тон на текста (от guidelines):** уважителен, спокоен, подкрепящ, **без** агресивни продажби, хумор или графични/драматични думи. Кратки изречения, ясни стъпки. Винаги на **„Вие"**.

Примерен микротекст: „Разбираме, че всеки случай е различен. Ще Ви съдействаме спокойно и организирано."

## 2. Цветова система

Палитрата стъпва на **два бранд цвята** — navy `#141e3c` и злато `#baad7b` — плюс бяло. Допълнителните нюанси са функционални оттенъци на същите цветове (за hover, граници, фонове), **не** нови акценти. Правило от guidelines: **не въвеждай нови наситени акцентни цветове.**

### 2.1 Tokens

```css
:root {
  /* === NAVY (основен / primary) === */
  --navy-900: #0e1530;   /* footer най-тъмно */
  --navy-800: #141e3c;   /* ★ БРАНД navy — header, hero overlay, .ds секции */
  --navy-700: #1d2a4f;
  --navy-600: #283a68;   /* hover върху тъмни повърхности */

  /* === GOLD (акцент / accent) === */
  --gold-700: #8f8253;   /* злато като ТЕКСТ върху бяло (мин. контраст, само едро) */
  --gold-600: #a89a64;
  --gold-500: #baad7b;   /* ★ БРАНД злато — CTA, акценти, линии, ::selection */
  --gold-400: #cabf93;   /* hover на бутони */
  --gold-300: #ddd4b4;   /* фини разделители, орнаменти */

  /* === НЕУТРАЛНИ === */
  --white:    #ffffff;   /* ★ основен фон на страницата */
  --paper:    #faf9f6;   /* по избор: едва топъл фон за редуване на секции */
  --line:     #e7e4dc;   /* hairline граници */

  /* === ТЕКСТ === */
  --ink-900:  #1b1b1d;   /* заглавия върху светло */
  --ink-700:  #353539;   /* основен текст (вариант на bootstrap #212529) */
  --ink-500:  #6b6b70;   /* приглушен текст */
  --on-dark:        #ffffff;  /* текст върху navy */
  --on-dark-muted:  #c3c8d4;
}
```

### 2.2 Семантични tokens (използвай ТЕЗИ в кода)

```css
:root {
  --bg-base: var(--white);
  --bg-alt: var(--paper);        /* по избор */
  --bg-inverse: var(--navy-800); /* тъмни секции (.ds) */
  --bg-footer: var(--navy-900);

  --text-primary: var(--ink-900);
  --text-body: var(--ink-700);
  --text-muted: var(--ink-500);

  --accent: var(--gold-500);
  --accent-hover: var(--gold-400);
  --accent-text: var(--gold-700);  /* злато като текст само върху светло, едро */

  --border-subtle: var(--line);
  --border-accent: var(--gold-500);
}

/* бранд правило: */
::selection { background-color: var(--gold-500); color: #fff; }
```

### 2.3 Тъмна секция (`.ds` — dark section, бранд конвенция)

```css
.ds { background-color: var(--navy-800); color: var(--on-dark); }
.ds h1, .ds h2, .ds h3, .ds h4, .ds h5, .ds h6 { color: #fff; }
.ds .accent { color: var(--gold-500); }
```

### 2.4 Контраст (критично — аудиторията често е възрастна и в стрес)

- **Злато НИКОГА като дребен текст върху бяло** — пада под AA. За дребен акцентен текст ползвай `--gold-700` (`#8f8253`) и само за едри/декоративни случаи.
- Body текст: `--ink-700`/`--ink-900` върху светло; `#ffffff` върху navy.
- Бутон: злато фон `--gold-500` + navy текст `--navy-800` → силен контраст.
- Минимум **AA 4.5:1** за текст, **3:1** за едри заглавия. Видим focus (златен контур 2px).

### 2.5 Разпределение

- **~65%** бяло (фон, въздух) · **~25%** navy (header, footer, акцентни/`.ds` секции) · **~10%** злато (само акценти — линии, CTA, иконки). Златото е „подправка", не основа.

## 3. Типография

Запазваме бранд спецификацията дословно: **Playfair Display (italic, 900)** за заглавия + **Montserrat** за текст. И двата са с пълна кирилица.

### 3.1 Шрифтове

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Playfair+Display:ital,wght@0,400..900;1,400..900&family=Montserrat:wght@400;500;600;700&display=swap&subset=cyrillic,cyrillic-ext" rel="stylesheet">
```

> ⚠️ Винаги `subset=cyrillic`. Проверявай с реален български текст (Ж, Щ, Ъ, Ю, Я), не с латиница.

```css
:root {
  --font-display: "Playfair Display", Georgia, serif;
  --font-body: "Montserrat", system-ui, sans-serif;
}
```

### 3.2 Правила за заглавия (бранд спецификация H1–H6)

```css
h1,h2,h3,h4,h5,h6 {
  font-family: var(--font-display);
  font-style: italic;          /* ★ бранд сигнатура */
  font-weight: 900;            /* ★ */
  line-height: 1.12;
  word-break: break-word;
  font-feature-settings: "lnum" 1;  /* lining numbers */
  color: var(--text-primary);
}
```

### 3.3 Типографска скала

```css
:root {
  --text-sm:   0.875rem;  /* 14px — captions */
  --text-base: 1rem;      /* 16px — body (бранд база) */
  --text-lg:   1.125rem;  /* 18px — lead абзац */
  --text-xl:   1.375rem;  /* H4 */
  --text-2xl:  clamp(1.6rem, 3vw, 2rem);    /* H3 */
  --text-3xl:  clamp(2rem, 4vw, 2.8rem);    /* H2 — бранд: 60px desktop → 2.8rem ≤992px */
  --text-h2:   clamp(2.8rem, 5vw, 3.75rem); /* едри H2 (60px) */
  --text-hero: clamp(2.8rem, 7vw, 5.5rem);  /* Hero H1 */

  --leading-body: 1.6;   /* body (бранд база 24px/16px=1.5; 1.6 за по-добра четимост) */
}

body { font-family: var(--font-body); font-weight: 400; font-size: var(--text-base); line-height: var(--leading-body); color: var(--text-body); background: var(--bg-base); }
```

### 3.4 Употреба

- **Hero H1:** Playfair italic 900. Може микс с акцентна дума в злато (виж лого/слоган стила).
- **Eyebrow / надзаглавие:** Montserrat, UPPERCASE, `letter-spacing: 0.22em`, `--text-sm`, цвят `--gold-700` или `--ink-500`. (Като „ЧЕСТ, ДОСТОЙНСТВО И ПОЧТЕНОСТ".)
- **Body:** Montserrat 400, `max-width: 65ch`, ляво подравнен. Не центрирай дълги абзаци.
- **H2 на секция:** едро Playfair italic 900, отдолу тънка златна линия (motif).

## 4. Лого

Логото е **векторизирано и готово за проекта** (виж папка `/logo`). Орнаментът-вълна през „А" е запазен; правописът на подзаглавието е **поправен**.

### 4.1 ⚠️ Поправка в логото

Подаденият draft съдържа правописна грешка: пише „**Трауна** агенция" вместо „**Траурна** агенция" (липсва „р"). Във всички генерирани асети това е **поправено**. Увери се, че никъде не се ползва старата сгрешена версия.

### 4.3 Правила за употреба

- **Clear space:** свободно поле от поне височината на буквата „А" от всички страни.
- **Минимален размер:** пълно лого ≥ 160px ширина; само-надпис ≥ 90px.
- **Фон:** предпочитан navy. Върху снимка — само mono-white върху достатъчно тъмен overlay.
- **Header:** използвай `amin-logo-on-dark.svg` (header е navy). За много компактен mobile header — `amin-wordmark-gold.svg`.
- **Забранено:** разтягане, сенки, контур, преоцветяване извън палитрата, въртене, поставяне върху пъстър фон без overlay.
- Доставяй като **SVG** (inline или `<img>` с `alt="Погребална агенция АМИН"`). Favicon: SVG + PNG fallback (32, 180, 512px).

### 4.4 Орнаментът като motif

Вълната под „А" е разпознаваем бранд елемент. Може да се ползва дискретно като **разделител между секции** (тънка златна вълнà/линия) — пести го, за да остане специален.

## 8. Компоненти

### 8.1 Header / навигация
- **Sticky.** Фон `--navy-800` (header е тъмен), с фина долна златна линия. (По избор: полупрозрачен над hero → плътен при скрол.)
- Лого вляво (`amin-logo-on-dark.svg`).
- Меню: Начало · За нас · Услуги · Галерия · Полезна информация · Контакти. Активен линк в злато.
- Вдясно: **двата телефона** с иконка (`0878 907 150`, `0897 389 953`) — `tel:` линкове, видими винаги. Mobile → ясен бутон „Обади се".
- Mobile: hamburger → full-screen navy overlay, центрирано меню, телефоните най-отдолу.

### 8.2 Бутони
```css
.btn-primary{ background:var(--gold-500); color:var(--navy-800); font-family:var(--font-body);
  font-weight:600; padding:.9rem 2.2rem; border-radius:var(--radius-pill); transition:all .25s ease; }
.btn-primary:hover{ background:var(--gold-400); transform:translateY(-2px); box-shadow:var(--shadow-md); }
.btn-outline{ background:transparent; color:var(--gold-700); border:1.5px solid var(--gold-500);
  border-radius:var(--radius-pill); padding:.85rem 2.1rem; }
.btn-outline:hover{ background:var(--gold-500); color:var(--navy-800); }
```
**Бранд правило: един основен CTA на секция.** Основният винаги е телефон: „Обади се – 0878 907 150". Вторичен: „Виж всички услуги".

### 8.3 Авторитетна лента (trust strip) — повтарящ се компонент
Хоризонтална лента веднага под Hero с 4–5 кратки точки за доверие (напр. „Денонощна реакция · Пълна организация · Собствена ритуална база · Транспорт в страната · Работа с институции"). Стил: navy или paper фон, точки разделени с тънка златна вертикална чертица, Montserrat, кратко. На mobile → 2 колони или хоризонтален скрол.

### 8.4 Услуги — карти (grid)
Бяла карта, `--radius-md`, `--shadow-sm` → hover `--shadow-md` + леко повдигане. Горе тънка line-иконка в злато, заглавие Playfair italic, кратък текст, линк „Научи повече →". Дискретна златна линия отгоре/вляво.

### 8.5 „Как протича процесът" — стъпки (повтарящ се компонент)
Всички услуги имат 4–5 номерирани стъпки. Компонент: голяма цифра (Playfair italic, злато) или кръгъл златен бадж + заглавие + кратък текст. Подреждане: вертикален timeline с тънка златна свързваща линия (desktop хоризонтален). Спокойни fade-up при скрол.

### 8.6 „Какво включва / Какво поемаме" — списъци
Сканируеми bullet списъци с дискретна златна чек-иконка или лява акцентна черта (`.accent-rule`). Щедро разстояние между редовете (`--space-4`), ключови думи bold `--ink-900`.

### 8.7 Цитат / акцентен блок
Голяма декоративна златна кавичка + текст Playfair italic + лява златна черта. За слогана и акцентите („Агенцията извършва услуги в цялата страна…").

### 8.8 FAQ акордеон (повтарящ се — всяка страница има ЧЗВ)
Въпрос (Montserrat 600) + chevron, разгъва отговор (Montserrat 400). Тънка `--line` граница, златен акцент на активния. Винаги придружено с **FAQ schema** (виж 14). Достъпен: `<button aria-expanded>`, клавиатура.

### 8.9 Форма за контакт / запитване
Бели полета, граница `--line`, focus → златна граница 2px (без тежки сенки). Етикети над полетата (Montserrat 500), edри полета `min-height:48px`. GDPR чекбокс + бутон „Изпрати запитване". Под формата: телефоните + „На разположение 24/7".

### 8.10 Офиси (4 локации)
Карти за всеки офис: иконка-пинче + адрес + `tel:` телефон. Google Maps embed (lazy). Виж реалните адреси в секция 12.

### 8.11 CTA лента (повтаряща се)
Тясна `.ds` (navy) лента между секциите: заглавие („Нуждаете се от съдействие") + кратък текст + основен телефон бутон. Дискретна, не агресивна.

### 8.12 Footer
`--navy-900`. Колона 1: лого + кратко изречение + слоган. Колони 2–5: 4-те офиса (адрес + телефон). Долна лента: © година, „Изработка: Linkbox.BG", линк към Поверителност. Заглавия в Playfair italic, злато.

## 10. Motion / анимации

Сдържано и бавно — контекстът го изисква.
- Page load: staggered fade-in + translateY 8–16px, 0.6–0.8s, ease-out, забавяне 80–120ms.
- Scroll reveal: фини fade-up (IntersectionObserver).
- Hover: меки 0.25s преходи, леко повдигане. Без bounce.
- **Без** автоплей видео, агресивен parallax, въртележки с бърз timing.
- Уважавай `prefers-reduced-motion: reduce` → изключи движенията.

```css
@media (prefers-reduced-motion: reduce){ *,*::before,*::after{ animation:none!important; transition:none!important; } }
```

## 11. Достъпност (приоритет)

- Контраст AA (виж 2.4). Body ≥ 16px.
- Видим focus state (златен 2px) на всичко интерактивно.
- Телефони като `tel:` — кликаеми на mobile. Touch таргети ≥ 44×44px.
- Семантичен HTML, йерархия H1→H2→H3, `lang="bg"`.
- Форми с `<label>`, ясни грешки на български. Акордеон с `aria-expanded`.

## 15. Do / Don't

| ✅ Прави | ❌ Избягвай |
|---|---|
| Бранд: само #141e3c + #baad7b + бяло | Нови наситени акцентни цветове |

| Злато само като акцент (~10%) | Големи златни площи/градиенти навсякъде |

| Сдържани, бавни fade анимации | Bounce, въртележки, автоплей |

| Поправено „Траурна агенция" | Старото сгрешено „Трауна" |
| Кирилица тествана с реален текст | Латиница за тест |
